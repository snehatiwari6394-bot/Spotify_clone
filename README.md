# Projects
Spotify Clone - Web Music Player

This is a clean and simple Spotify-inspired web music player built using basic HTML, CSS, and JavaScript. I created this frontend project to practice web development by building a functional UI that actually plays songs, handles play/pause state, tracks duration, and lets you skip or adjust the volume.

Features & Overview

The player features a custom song list with cover art, a bottom playback bar with a progress slider, volume controls, and a playing indicator GIF. There's also a simple navigation bar with a built-in "About" popup modal that shares details about the project.

Songs included in the playlist:
Mero Vrindavan, Radha Raman Hare Hare, Joi Joi Pyaaro Kare, De Ke Charnon Ki Seva, Tu Hi Mera Shab Hai, Tere Liye, Mann Mera, and Deewaniyat.

How to Run

Simply clone or download this repository and open index.html in your web browser. Make sure all images, CSS, and JavaScript files are in the same directory structure.
